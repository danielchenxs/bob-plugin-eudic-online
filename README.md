# 欧路在线词典 Bob 插件

免配置查询欧路词典的英汉、英英释义和美英发音，支持常见英文单词和简短词组。需要 macOS 13 或更新版本、Bob 1.21.0 或更新版本和网络连接。

## 安装

双击 [dist/eudic-online-0.7.0.bobplugin](dist/eudic-online-0.7.0.bobplugin) 安装。在 Bob「偏好设置 → 服务 → 文本翻译」中添加并启用「欧路在线词典」服务，并开启 Markdown 译文渲染；查询 `embedding`、`hello` 或 `take off`，点击美/英发音按钮即可播放。Bob 原生音标与发音按钮按美音、英音顺序分两行显示。无需欧路账号或密钥。

在 Bob「偏好设置 → 服务 → 文本翻译 → 欧路在线词典」的服务设置中，可调整六项菜单：音标与发音（美英、仅美、仅英、隐藏）、英英释义、词根词缀、原形与词形、词组，以及听力例句数量（关闭、1、2、4 条）。默认全部显示，例句显示 4 条。中文词性与释义始终显示。调整后点击「保存」；设置对新查询生效，旧历史记录不会自动更新。

## 说明

释义来自欧路公开移动网页的纯文本词条。Bob 原生卡片先显示美英音标与发音，再按网页原词性显示中文释义；正文随后显示页面提供的英英释义、词根词缀、可用的基词建议、词组和最多 4 条双语听力例句及来源。英英部分缺失时保留中文结果，无法完整解析时会显示提示。网页列出的时态等形式按原标签显示；桌面页建议词还须经该词移动页的「时态」字段核实包含当前查询词，才作为「原形」显示。无法核实时仅显示可点击建议，不把建议冒充词根。桌面页或候选页不可用时不影响查词。「在欧路听原声」通过欧路客户端链接打开该词条，需安装欧路词典；「更多例句」打开公开网页。Bob 内的美英发音按钮播放本词，例句原声需到欧路词典中收听。

词根词缀取自[维基词典英语词源](https://en.wiktionary.org/wiki/Wiktionary:Main_Page)（CC BY-SA）。只有来源明确写出词干加前缀或后缀时才拆解，`embedding` 可显示 `embed + -ing`，并进一步显示 `embed` 的 `em- + bed`；历史词源如 `explore` 保留原文及其中的不确定性，不强行拆成现代英语词缀。没有可用英语词源或网络异常时显示“资料暂无”，不影响欧路释义。

移动网页的核心释义与词组无需图片字。网页分别提供英美音标时各自显示；只提供通用音标时，英美两处都显示该音标。查询不到词条或网络出错时会返回明确提示。

## 开发

`npm test` 运行解析和回调测试；`npm run verify:etymology` 验证三个线上英语词源并写入 `tests/wiktionary-verification.json`；`npm run verify:live` 查询线上词条与英美音频，并把验证结果写入 `tests/live-verification.json`；`npm run pack` 生成 `.bobplugin` 安装包。插件包只包含 Bob 需要的 `info.json` 和 `main.js`。
