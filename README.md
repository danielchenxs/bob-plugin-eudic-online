# 欧路在线词典 Bob 插件

免配置查询欧路词典的英汉、英英释义和美英发音，支持常见英文单词和简短词组。需要 macOS 13 或更新版本、Bob 1.21.0 或更新版本和网络连接。

## 安装

双击 [dist/eudic-online-0.8.1.bobplugin](dist/eudic-online-0.8.1.bobplugin) 安装。在 Bob「偏好设置 → 服务 → 文本翻译」中添加并启用「欧路在线词典」服务，并开启 Markdown 译文渲染；查询 `embedding`、`hello` 或 `take off`，点击美/英发音按钮即可播放。Bob 原生音标与发音按钮按美音、英音顺序分两行显示。普通查词无需欧路账号或密钥。核心释义到达后会先显示预览，原生发音按钮在最终卡片中出现。

在 Bob「偏好设置 → 服务 → 文本翻译 → 欧路在线词典」的服务设置中，可调整原有六项菜单：音标与发音（美英、仅美、仅英、隐藏）、英英释义、词根词缀、原形与词形、词组，以及听力例句数量（关闭、1、2、4 条）。默认全部显示，例句显示 4 条。中文词性与释义始终显示。还可选择“自动加入欧路生词本”（默认关闭）。调整后点击「保存」；设置对新查询生效，旧历史记录不会自动更新。

## 自动加入生词本

在[欧路开放 API 页面](https://my.eudic.net/OpenAPI/Doc_Index)登录并获取完整 API 授权信息，然后在插件服务设置中填入「欧路 API 授权信息」。该输入框会隐藏输入内容；请按欧路提供的完整格式填写，不要自行添加 `Bearer`。生词本 ID 默认 `0`，如使用其他分组请填写对应数字 ID；较长的数字 ID 会按原字符串发送，不会四舍五入。开启「自动加入欧路生词本」后点击「保存」，可使用 Bob 的「验证」按钮检查授权和分组。

仅查词成功时同步当前查询词，不导入历史、例句或推测的原形。自动同步默认关闭，关闭时不访问账号 API。同步失败或限频不会丢失释义；正文会显示简短状态。「近期已加入（本机记录）」表示插件在 24 小时内收到过成功响应，不代表实时查询了生词本。欧路 API 有请求额度，插件按授权分别限制调用频率，并将授权哈希对应的调用时间与短期退避保存在私有沙盒，以便重新启动后继续限频。403/429 后至少暂缓一小时；授权失败则等待更换授权信息。若沙盒文件不可用或 Bob 无法计算授权哈希，限频仍在当前运行期间生效，跨重启保护可能失效。凭据不会写入缓存或限频文件。

## 说明

释义来自欧路公开移动网页的纯文本词条。Bob 原生卡片先显示美英音标与发音，再按网页原词性显示中文释义；正文随后显示页面提供的英英释义、词根词缀、可用的基词建议、词组和最多 4 条双语听力例句及来源。英英部分缺失时保留中文结果，无法完整解析时会显示提示。网页列出的时态等形式按原标签显示；桌面页建议词还须经该词移动页的「时态」字段核实包含当前查询词，才作为「原形」显示。无法核实时仅显示可点击建议，不把建议冒充词根。桌面页或候选页不可用时不影响查词。移动页成功后先显示词头、音标文字、中文释义和已取得的正文；桌面提示与词源并行加载，最终卡片保留 Bob 原生中文义项和发音按钮。公开移动/桌面词条缓存 24 小时，词源解析缓存 7 天。「在欧路听原声」通过欧路客户端链接打开该词条，需安装欧路词典；「更多例句」打开公开网页。Bob 内的美英发音按钮播放本词，例句原声需到欧路词典中收听。

词根词缀取自[维基词典英语词源](https://en.wiktionary.org/wiki/Wiktionary:Main_Page)（CC BY-SA）。只有来源明确写出词干加前缀或后缀时才拆解，`embedding` 可显示 `embed + -ing`，并进一步显示 `embed` 的 `em- + bed`；历史词源如 `explore` 保留原文及其中的不确定性，不强行拆成现代英语词缀。没有可用英语词源或网络异常时显示“资料暂无”，不影响欧路释义。

对 `eludes` 等变形词，只有欧路词条在时态、复数或比较级等字段明确列出当前查询词时，才采用其原形词头下的释义；原形会显示在附加信息中。词源、链接和自动加入生词本仍使用实际查询词。未列出的变形不会凭拼写猜测。

移动网页的核心释义与词组无需图片字。网页分别提供英美音标时各自显示；只提供通用音标时，英美两处都显示该音标。查询不到词条或网络出错时会返回明确提示。

## 开发

`npm test` 运行解析和回调测试；`npm run verify:etymology` 验证三个线上英语词源并写入 `tests/wiktionary-verification.json`；`npm run verify:live` 查询线上词条与英美音频，并把验证结果写入 `tests/live-verification.json`；`npm run pack` 生成 `.bobplugin` 安装包。插件包只包含 Bob 需要的 `info.json` 和 `main.js`。
